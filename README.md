Medical Report System
This project is a Java based GUI application that generates medical reports. It allows the user to enter patient details, test information, doctor name, and diagnosis, and displays a structured report similar to hospital reports.
Features
User can enter patient details such as name, age and gender
Test name and result can be added
Doctor name and diagnosis can be entered
Generates a formatted medical report
Simple and user friendly interface
Technologies Used
Java
Java Swing
How to Run
Open the project in Visual Studio Code or any Java IDE
Compile the program using javac MedicalReportGUI.java
Run the program using java MedicalReportGUI
